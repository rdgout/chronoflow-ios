# Phase 16a: member wizard

The My trips + and empty-state Plan a trip action present Where → Outbound in a full-screen native navigation stack. From/To, swap, same-airport validation, debounced airport search, native airport wall-clock date/time pickers, stop insertion/removal and field errors are implemented in English and Dutch, with generated light/dark tokens. The Home airport search field is supported by the shared sheet; its flight-home entry comes in 16b.

`TripWizard/Model` contains the portable model, recovery and RN ports. `TripWizardUI` is a separate MainActor target with its own String Catalog. No new per-view Dynamic Type cap, absolute device geometry, snapshot suite or reference image is added. Native safe areas, scrolling, `safeAreaInset` and nested `ViewThatFits` handle compact widths and larger text. Tasks attach to mounted content; screen containers use `.accessibilityElement(children: .contain)`.

The hidden `drafts` row has the fixed id `member-wizard`. It stores the step, airport sheet, airport metadata, entered/first-trip flags and form. It expires at 30 minutes since the last write, with fractional timestamps, and is excluded from both draft listing APIs. × discards immediately before user input and asks the designed discard alert after input. Closing flushes pending writes before deleting; instance and revision guards prevent old writes from resurrecting it. `didSave` and a persisted `savedTripId` delete recovery as the save integration seam for 16c. Relaunch recovery opens automatically over the tabs. The latest non-deleted trip by departure supplies From; no latest trip records `firstTrip`.

Sources are read-only RN `e24872a` (`src/trips/date-time.ts`, `validation.ts`, `journey.ts`, `form.ts`, `review.ts`, `wizard-presentation.ts` and their tests), WizardSpec/Wizard/WizardSheet and the named wrapper boards, and web `d54ca6cf`. Dutch copy comes from RN `nl.json`, then web `lang/nl.json`, then translation. The existing airport DTO, DataSource method, mock and API client match web `routes/api.php`, `Api/V1/AirportIndexController` and `Api/V1/SearchAirportsRequest`: public GET `/v1/airports`, query 2–60 characters, default limit 8 (1–20), 60 requests/minute. One search actor spans the wizard's sheets and successive opens; it debounces 350 ms, spaces admitted requests by at least 1.02 s, cancels stale searches and observes 429 waits.
