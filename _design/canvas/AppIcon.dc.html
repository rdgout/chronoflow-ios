App icon · appearances

The ChronoFlow mark rebuilt as vectors from the supplied 512 px PNG (same gradient, same moon; checked pixel by pixel), so every appearance comes from the same two layers. Files are in icon/ next to this board.

iOS 16–18 · flat images

Every file is a full-bleed 1024 × 1024 square; iOS applies the corner mask. iOS 16 and 17 only use Default. Dark keeps the night sky but drops the orange horizon to an ember and gives the moon a soft glow, so it sits with other dark icons. Tinted is grayscale: the system colours it with the tint the person picked.

iOS 26 · Liquid Glass (Icon Composer)

One .icon file gives every appearance. Two layers: the sky gradient (no glass) and a slightly bolder moon outline (2.6 instead of 2 on the 24 grid) that gets the glass. The tiles below approximate the look; Icon Composer renders the real refraction and highlights.

Layers

Vectors in icon/layers/. The moon is the current lucide Moon path (the one the app uses for sleep), stroke 2, round caps, centred, 24-unit box at 50% of the canvas.

Android · adaptive icon

Foreground and background are separate 1024 layers on a 108 dp canvas; launchers show the middle 72 dp in their own shape. The moon is drawn smaller here so it looks the same size as on iOS. The monochrome layer is used for themed icons (Android 13+).

Icon Composer

  • ChronoFlow.icon is a hand-written starter (moon-glass.svg as a glass group, background.svg as a group without glass). Open it in Icon Composer and check it before shipping; if it doesn’t open, rebuild it from the two layers in a few minutes.
  • Dark: set the sky layer’s Dark appearance to background-dark.svg. The moon stays dawn.
  • Moon group: Liquid Glass on, translucency about 40%, neutral shadow. Sky group: Liquid Glass off, no shadow.
  • Clear and Tinted come from the moon’s shape; nothing extra to draw.
  • Keep it simple: no text, no extra stars. The glass reads the outline best at this weight.
